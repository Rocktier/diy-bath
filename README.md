# DIY Bath — 多端浴室柜定制画图工具

本仓库按端（platform）分目录组织，每个端一个文件夹：

| 目录 | 端 | 状态 |
|------|----|------|
| `web/` | 网页（Three.js 单文件 MVP） | 已实现 |
| `android/` | Android 客户端 | 待开发 |
| `ios/` | iOS 客户端 | 待开发 |
| `macos/` | macOS 客户端 | 待开发 |
| `windows/` | Windows 客户端 | 待开发 |

规划台账（planning-with-files）位于仓库根目录：`task_plan.md`、`findings.md`、`progress.md`。

各端详情见对应目录内的 README。
