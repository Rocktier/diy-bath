## 差距分析在哪

完整的差距清单和执行顺序建议，见 `docs/台账.md` 的
「待办 → 最优先：3D 轴测图 + 模型表达力」一节。

简要版：

- **缺 3D 渲染层**（要引入 Three.js，数据层可复用）
- **缺模型表达力**：斜腿、玻璃门、内嵌面板、镜柜分格
- **缺带箭头的尺寸标注线**（最快能补，纯投影层）
