# 浴室柜草图生成器 实施计划 · 第一期（引擎 + 界面）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 一个本地网页应用，填入浴室柜参数，实时输出正视图 / 俯视图 / 剖面图三张白模风格 SVG，可导出 PNG 与 SVG。

**Architecture:** 参数 → 布局求解器 → 零件清单（3D 盒子）→ 三视图投影 → SVG 字符串。全部为无 DOM 依赖的纯函数，Node 直接跑测试。三个视图来自同一份零件清单，因此几何必然一致。

**Tech Stack:** 原生 ES Modules，无构建步骤，无第三方依赖。Node 26 仅用于跑测试。Tauri 打包属第二期，不在本计划内。

## Global Constraints

以下约束适用于本计划的每一个任务，逐字来自设计文档 `docs/superpowers/specs/2026-10-03-浴室柜草图生成器-design.md`。

- **所有尺寸自由输入，不设档位、不做合法性校验、不给"不标准"警告。** 这是项目最重要的设计原则（规格 §2.3）。任何"这个值不合理"式的校验代码都视为 bug。
- 面板缝宽默认值 **2mm**，来自团体标准 T/FSWA 01-2021 的位差度要求，全项目唯一取值点在 `cabinet.gap`。
- 风格固定为 **SketchUp 白模**：纯色块 + 描边。**禁止** `filter`、`gradient`、`pattern`、`shadow`。
- 渲染层只有一种文字颜色（`dimText`），因为白模风格不需要多色文字。
- 尺寸单位一律 **mm**。SVG 的 `viewBox` 单位就是 mm，因此描边宽度、字号都用 mm 表达，保证不同柜子尺寸下视觉大小一致。
- 不得引入任何第三方 npm 依赖。
- 不得引入构建步骤（无 webpack / vite / rollup）。
- 台面深度**不存在独立字段**，沿用 `cabinet.depth`；台面相对柜体的差异只由 `top.overhang` 表达。
- 抽屉滑轨**不区分**三节/两节，统一画法。
- 一体盆**要画盆胆轮廓**，只取消台面与盆之间的接缝线；不是画成一个没有内部结构的整块。
- 坐标约定：原点 = 墙面与地面交线、柜体外侧边缘。x 向右，**y 向上**，z 向房间内侧。`project.js` 负责翻成屏幕坐标。

```js
const tests = [];

export function test(name, fn) {
  tests.push({ name, fn });
}

export function eq(actual, expected, msg = '') {
  if (actual !== expected) {
    throw new Error(`${msg}\n  期望: ${expected}\n  实际: ${actual}`);
  }
}

export function close(actual, expected, tol = 0.001, msg = '') {
  if (!Number.isFinite(actual) || Math.abs(actual - expected) > tol) {
    throw new Error(`${msg}\n  期望: ${expected} ±${tol}\n  实际: ${actual}`);
  }
}

export function throws(fn, msg = '应当抛错但没有') {
  try {
    fn();
  } catch {
    return;
  }
  throw new Error(msg);
}

export function runAll() {
  let pass = 0;
  const failures = [];
  for (const t of tests) {
    try {
      t.fn();
      pass++;
      console.log(`  ok   ${t.name}`);
    } catch (e) {
      failures.push(t.name);
      console.error(`  FAIL ${t.name}\n       ${e.message.replace(/\n/g, '\n       ')}`);
    }
  }
  console.log(`\n${pass} passed, ${failures.length} failed`);
  if (failures.length) process.exit(1);
}
```

```js
export function solve(spec) {
  const { cabinet, top, bands } = spec;
  const gap = cabinet.gap;
  const baseY = cabinet.mount === 'wall' ? cabinet.wallGap : cabinet.toe.height;
  const carcassTopY = baseY + cabinet.height;
  const ctTopY = carcassTopY + top.thickness;
  const netW = cabinet.width - 2 * cabinet.sidePanel;

  const bandGaps = gap * Math.max(0, bands.length - 1);
  const availH = cabinet.height - bandGaps;
  const totalRows = bands.reduce((s, b) => s + sum(b.rows), 0);

  let cursor = baseY;
  const bandLayouts = bands.map((band, bandIndex) => {
    const s = sum(band.rows);
    const h = availH * (s / totalRows);
    const bl = { band, bandIndex, y: cursor, h, cols: [], rows: [], cells: [] };
    cursor += h + gap;

    const rowGaps = gap * Math.max(0, band.rows.length - 1);
    const rowUsable = h - rowGaps;
    let ry = bl.y;
    for (const r of band.rows) {
      const rh = rowUsable * (r / s);
      bl.rows.push({ y: ry, h: rh });
      ry += rh + gap;
    }

    return bl;
  });

  for (const bl of bandLayouts) {
    const n = bl.band.cols.length * bl.band.rows.length;
    if (bl.band.cells && bl.band.cells.length !== n) {
      throw new Error(
        `分区 #${bl.bandIndex + 1} 的 cells 长度 ${bl.band.cells.length} != 列×行 ${n}`,
      );
    }
  }

  return {
    gap, baseY, carcassTopY, ctTopY, netW,
    bands: bandLayouts,
    cells: [],
    basins: [],
  };
}

  return arr.reduce((a, b) => a + b, 0);
```

把 `src/solve.js` 中带循环之后、`for (const bl of bandLayouts)` 之前的部分，
在每条带内追加列分配，并把 `cells` 填充进去。完整替换后的 `solve()`：

```js
export function solve(spec) {
  const { cabinet, top, bands } = spec;
  const gap = cabinet.gap;
  const baseY = cabinet.mount === 'wall' ? cabinet.wallGap : cabinet.toe.height;
  const carcassTopY = baseY + cabinet.height;
  const ctTopY = carcassTopY + top.thickness;
  const netW = cabinet.width - 2 * cabinet.sidePanel;

  const bandGaps = gap * Math.max(0, bands.length - 1);
  const availH = cabinet.height - bandGaps;
  const totalRows = bands.reduce((s, b) => s + sum(b.rows), 0);

  let cursor = baseY;
  const bandLayouts = bands.map((band, bandIndex) => {
    const s = sum(band.rows);
    const h = availH * (s / totalRows);
    const bl = { band, bandIndex, y: cursor, h, cols: [], rows: [], cells: [] };
    cursor += h + gap;

    const rowGaps = gap * Math.max(0, band.rows.length - 1);
    const rowUsable = h - rowGaps;
    let ry = bl.y;
    for (const r of band.rows) {
      const rh = rowUsable * (r / s);
      bl.rows.push({ y: ry, h: rh });
      ry += rh + gap;
    }

    const colGaps = gap * Math.max(0, band.cols.length - 1);
    const colUsable = netW - colGaps;
    const cs = sum(band.cols);
    let cx = cabinet.sidePanel;
    for (const c of band.cols) {
      const cw = colUsable * (c / cs);
      bl.cols.push({ x: cx, w: cw });
      cx += cw + gap;
    }

    return bl;
  });

  const cells = [];

  for (const bl of bandLayouts) {
    const { band } = bl;
    const n = band.cols.length * band.rows.length;
    if (band.cells && band.cells.length !== n) {
      throw new Error(
        `分区 #${bl.bandIndex + 1} 的 cells 长度 ${band.cells.length} != 列×行 ${n}`,
      );
    }
    let i = 0;
    for (let r = 0; r < bl.rows.length; r++) {
      for (let c = 0; c < bl.cols.length; c++) {
        const cell = {
          x: bl.cols[c].x,
          y: bl.rows[r].y,
          w: bl.cols[c].w,
          h: bl.rows[r].h,
          kind: band.cells ? band.cells[i] : band.kind,
          handle: Array.isArray(band.handle) ? band.handle[i] : band.handle,
          band: bl.bandIndex,
          col: c,
          row: r,
        };
        bl.cells.push(cell);
        cells.push(cell);
        i++;
      }
    }
  }

  return {
    gap, baseY, carcassTopY, ctTopY, netW,
    bands: bandLayouts,
    cells,
    basins: [],
  };
}

function sum(arr) {
  return arr.reduce((a, b) => a + b, 0);
}
```

```js
function basinXs(basin, cabinet) {
  if (basin.count === 2) {
    const groupW = basin.width * 2 + basin.gap;
    const left = (cabinet.width - groupW) / 2;
    return [left, left + basin.width + basin.gap];
  }
  if (typeof basin.position === 'number') return [basin.position];
  return [(cabinet.width - basin.width) / 2];
}

function basinZ(basin, top, topDepth) {
  const bias = basin.depthBias ?? 0.5;
  return (
    top.backsplash.thickness +
    (topDepth - top.backsplash.thickness - basin.depth) * (1 - bias)
  );
}
```

```js
    x,

    d: basin.depth,
    h: basin.height,
```

```js
import { solve } from './solve.js';

export function parts(spec) {
  const L = solve(spec);
  const { cabinet, top, mirror } = spec;
  const { width: W, depth: D, backPanel: BP, bottomPanel: BoP, toe } = cabinet;
  const out = [];

  if (cabinet.mount === 'floor') {
    out.push({
      kind: 'toe',
      x: toe.inset, y: 0, z: 0,
      w: W - 2 * toe.inset, h: toe.height, d: D - toe.inset,
    });
  }

  out.push({ kind: 'carcass', x: 0, y: L.baseY, z: 0, w: W, h: cabinet.height, d: D });
  out.push({ kind: 'backPanel', x: 0, y: L.baseY, z: 0, w: W, h: cabinet.height, d: BP });
  out.push({
    kind: 'bottomPanel',
    x: 0, y: L.baseY + cabinet.height - BoP, z: 0, w: W, h: BoP, d: D,
  });
  out.push({
    kind: 'sidePanel',
    x: 0, y: L.baseY, z: 0, w: cabinet.sidePanel, h: cabinet.height, d: D,
  });

  const ctW = W + 2 * top.overhang;
  out.push({
    kind: 'top',
    x: -top.overhang, y: L.carcassTopY, z: 0,
    w: ctW, h: top.thickness, d: D + top.overhang,
  });
  out.push({
    kind: 'backsplash',
    x: -top.overhang, y: L.ctTopY, z: 0,
    w: ctW, h: top.backsplash.height, d: top.backsplash.thickness,
  });

  if (mirror) {
    const mw = mirror.width ?? W;
    out.push({
      kind: 'mirror',
      x: (W - mw) / 2,
      y: L.ctTopY + top.backsplash.height + mirror.gap,
      z: 0, w: mw, h: mirror.height, d: mirror.depth,
    });
  }

  return out;
}
```

### Task 7: project 三视图投影

**Files:**
- Create: `src/project.js`
- Create: `test/project.test.js`
- Modify: `test/run.js`

**Interfaces:**
- Consumes: `parts(spec) → Part[]` from `src/parts.js`；`solve(spec) → Layout`
- Produces:
  - `front(ps, spec, L) → Shape[]`
  - `plan(ps, spec, L) → Shape[]`
  - `section(ps, spec, L) → Shape[]`
  - `bbox(shapes, pad?) → [minX, minY, w, h]`

  ```js
  Shape =
    | { shape:'rect',    part, x, y, w, h, rx?, fill?, stroke?, sw?, dash?, op?, bleed? }
    | { shape:'line',    part, x1, y1, x2, y2, stroke?, sw?, dash?, op?, bleed? }
    | { shape:'ellipse', part, cx, cy, rx, ry, fill?, stroke?, sw?, bleed? }
    | { shape:'text',    part, x, y, text, size, anchor?, baseline?, fill? }

  `fill` / `stroke` 存**调色板键名**（如 'top'、'stroke'），render.js 负责解析成色值。
  `fill: null` 表示不填充；`stroke: null` 表示不描边。
  `bleed: true` 的图形（墙、地面线）不参与 bbox 计算。
  三个投影的坐标：front = (x, -y)；plan = (x, z)；section = (z, -y)。
  ```

**为什么 section 里要加"分区示意条"：**
剖面是沿宽度切的，只能看到柜深方向的截面，看不出宽度方向有几个格子。
但你明确要了"剖面/内部分布"。因此剖面图底部附一条**分区示意条**，
按 `cell.w` 比例画出每个格子并按 kind 区分。它也让"三视图一致"成为可断言的：
分区示意条的格子数必须等于 `Layout.cells.length`。

```js
import { solve } from './solve.js';

const PAD = 40;
const orderOf = (p) => p.order ?? p.z + p.d;
const fy = (y) => -y;

export function bbox(shapes, pad = PAD) {
  const xs = [];
  const ys = [];
  for (const s of shapes) {
    if (s.bleed) continue;
    if (s.shape === 'rect') { xs.push(s.x, s.x + s.w); ys.push(s.y, s.y + s.h); }
    else if (s.shape === 'line') { xs.push(s.x1, s.x2); ys.push(s.y1, s.y2); }
    else if (s.shape === 'ellipse') { xs.push(s.cx - s.rx, s.cx + s.rx); ys.push(s.cy - s.ry, s.cy + s.ry); }
    else if (s.shape === 'text') {
      const size = s.size ?? 20;
      const half = s.text.length * size * 0.45;
      const anchor = s.anchor ?? 'middle';
      const x0 = anchor === 'start' ? s.x : anchor === 'end' ? s.x - 2 * half : s.x - half;
      xs.push(x0, x0 + 2 * half);
      ys.push(s.y, s.y + size);
    }
  }
  const minX = Math.min(...xs) - pad;
  const minY = Math.min(...ys) - pad;
  return [minX, minY, Math.max(...xs) - minX + pad, Math.max(...ys) - minY + pad];
}

function cabMid(ps) {
  const c = ps.find((p) => p.kind === 'carcass');
  return c ? c.x + c.w / 2 : 0;
}

function cellFront(p, mid) {
  const out = [{ shape: 'rect', part: 'cell', x: p.x, y: fy(p.y + p.h), w: p.w, h: p.h, fill: 'cell' }];
  const h = p.meta.handle;
  const leftSide = p.x + p.w / 2 < mid;
  if (h === 'gola') {
    out.push({ shape: 'rect', part: 'cell', x: p.x + 2, y: fy(p.y + p.h) , w: p.w - 4, h: 20, fill: 'basinInner', stroke: null });
  } else if (h === 'bar-h') {
    const len = Math.min(240, p.w * 0.6);
    out.push({
      shape: 'rect', part: 'handle',
      x: p.x + (p.w - len) / 2, y: fy(p.y + 34 + 14),
      w: len, h: 14, rx: 7, fill: 'handle',
    });
  } else if (h === 'bar-v') {
    const len = Math.min(260, p.h * 0.5);
    const hx = leftSide ? p.x + p.w - 64 : p.x + 49;
    out.push({
      shape: 'rect', part: 'handle',
      x: hx, y: fy(p.y + p.h / 2 + len / 2),
      w: 15, h: len, rx: 7.5, fill: 'handle',
    });
  } else if (h === 'knob') {
    out.push({
      shape: 'ellipse', part: 'handle',
      cx: leftSide ? p.x + p.w - 60 : p.x + 60, cy: fy(p.y + p.h / 2),
      rx: 10, ry: 10, fill: 'handle',
    });
  }
  return out;
}

function basinFront(p) {
  const m = p.meta;
  const top = fy(p.y + p.h);
  if (m.shape === 'ellipse') {
    return [
      { shape: 'ellipse', part: 'basin', cx: p.x + p.w / 2, cy: top + p.h / 2, rx: p.w / 2, ry: p.h / 2, fill: 'basin' },
      { shape: 'ellipse', part: 'basinInner', cx: p.x + p.w / 2,
        cy: top + m.wall + (p.h - m.wall - m.wallBottom) / 2,
        rx: p.w / 2 - m.wall, ry: (p.h - m.wall - m.wallBottom) / 2, fill: 'basinInner' },
    ];
  }
  const cavH = p.h - m.wall - m.wallBottom;
  return [
    { shape: 'rect', part: 'basin', x: p.x, y: top, w: p.w, h: p.h, rx: m.radius, fill: 'basin' },
    { shape: 'rect', part: 'basinInner', x: p.x + m.wall, y: top + m.wall,
      w: p.w - 2 * m.wall, h: cavH, rx: Math.max(0, m.radius - m.wall), fill: 'basinInner' },
  ];
}

function faucetFront(p) {
  return [
    { shape: 'rect', part: 'faucet', x: p.x, y: fy(p.y + p.h), w: p.w, h: p.h, rx: 10, fill: 'faucet' },
    { shape: 'rect', part: 'faucet', x: p.x - 4, y: fy(p.y + p.h) - 12, w: p.w + 8, h: 12, rx: 6, fill: 'faucet' },
  ];
}

export function front(ps, spec, L) {
  const sh = [{ shape: 'rect', part: 'wall', x: -600, y: -3000, w: 2600, h: 3200, fill: 'wall', stroke: null, bleed: true }];
  const mid = cabMid(ps);

  for (const p of [...ps].sort((a, b) => orderOf(a) - orderOf(b))) {
    switch (p.kind) {
      case 'backPanel': case 'bottomPanel': case 'sidePanel':
      case 'shelf': case 'drawerBox': case 'rail':
        break;
      case 'basin': sh.push(...basinFront(p)); break;
      case 'faucet': sh.push(...faucetFront(p)); break;
      case 'cell': sh.push(...cellFront(p, mid)); break;
      case 'mirror':
        sh.push({ shape: 'rect', part: 'mirror', x: p.x, y: fy(p.y + p.h), w: p.w, h: p.h, rx: 4, fill: 'mirror' });
        sh.push({ shape: 'rect', part: 'mirrorInner', x: p.x + 22, y: fy(p.y + p.h - 22), w: p.w - 44, h: p.h - 44, rx: 3, fill: 'mirrorInner' });
        break;
      default:
        sh.push({ shape: 'rect', part: p.kind, x: p.x, y: fy(p.y + p.h), w: p.w, h: p.h, fill: p.kind });
    }
  }

  sh.push({ shape: 'line', part: 'floor', x1: -300, y1: 0, x2: 1300, y2: 0, stroke: 'floor', sw: 1.4, bleed: true });
  return sh;
}

export function plan(ps, spec, L) {
  const { cabinet, top } = spec;
  const D = cabinet.depth;
  const sh = [];
  const t = ps.find((p) => p.kind === 'top');
  const bs = ps.find((p) => p.kind === 'backsplash');
  const bsT = bs ? bs.d : top.backsplash.thickness;

  sh.push({ shape: 'line', part: 'floor', x1: -80, y1: 0, x2: t.w + 80, y2: 0, stroke: 'floor', sw: 1.4, bleed: true });

  if (t) sh.push({ shape: 'rect', part: 'top', x: t.x, y: t.z, w: t.w, h: t.d, fill: 'top' });
  if (bs) sh.push({ shape: 'rect', part: 'backsplash', x: bs.x, y: bs.z, w: bs.w, h: bs.d, fill: 'backsplash' });

  sh.push({ shape: 'rect', part: 'carcass', x: 0, y: bsT, w: cabinet.width, h: D - bsT - 20,
            fill: null, stroke: 'stroke', sw: 0.9, dash: '16 11' });

  for (const c of L.cells) {
    sh.push({ shape: 'line', part: 'cell', x1: c.x + c.w / 2, y1: bsT + 6, x2: c.x + c.w / 2, y2: D - 26,
              stroke: 'stroke', sw: 0.8, dash: '12 9', op: 0.5 });
  }

  for (const p of ps.filter((x) => x.kind === 'basin')) {
    if (p.meta.type !== 'integral') {
      sh.push({ shape: 'rect', part: 'basin', x: p.x, y: p.z, w: p.w, h: p.d, rx: p.meta.radius, fill: 'basin' });
      sh.push({ shape: 'rect', part: 'basinInner', x: p.x + p.meta.wall, y: p.z + p.meta.wall,
                w: p.w - 2 * p.meta.wall, h: p.d - 2 * p.meta.wall,
                rx: Math.max(0, p.meta.radius - p.meta.wall), fill: 'basinInner' });
    }
    sh.push({ shape: 'ellipse', part: 'drain', cx: p.x + p.w / 2, cy: p.z + p.d / 2, rx: 20, ry: 20,
              fill: null, stroke: 'stroke', sw: 0.8 });
  }

  for (const p of ps.filter((x) => x.kind === 'faucet')) {
    sh.push({ shape: 'ellipse', part: 'faucet', cx: p.x + p.w / 2, cy: p.z + 20, rx: 26, ry: 26, fill: 'faucet' });
    sh.push({ shape: 'rect', part: 'faucet', x: p.x + p.w / 2 - 9, y: p.z + 20, w: 18,
              h: Math.max(0, p.d - 20 - 30), fill: 'faucet' });
  }

  const m = ps.find((x) => x.kind === 'mirror');
  if (m) {
    sh.push({ shape: 'rect', part: 'mirror', x: m.x, y: -m.d - 20, w: m.w, h: m.d,
              fill: null, stroke: 'stroke', sw: 1, dash: '14 10' });
  }
  return sh;
}

export function section(ps, spec, L) {
  const { cabinet, top } = spec;
  const D = cabinet.depth;
  const sh = [];
  const get = (k) => ps.find((p) => p.kind === k);

  sh.push({ shape: 'rect', part: 'wall', x: -40, y: fy(L.ctTopY + top.backsplash.height + 900),
            w: 40, h: 3000, fill: 'wallT', stroke: 'stroke', sw: 1, bleed: true });
  sh.push({ shape: 'line', part: 'floor', x1: -120, y1: 0, x2: D + 160, y2: 0, stroke: 'floor', sw: 1.4, bleed: true });

  const bp = get('backPanel');
  if (bp) sh.push({ shape: 'rect', part: 'backPanel', x: bp.z, y: fy(bp.y + bp.h), w: bp.d, h: bp.h, fill: 'carcass' });
  const bo = get('bottomPanel');
  if (bo) sh.push({ shape: 'rect', part: 'carcass', x: bo.z, y: fy(bo.y + bo.h), w: bo.d, h: bo.h, fill: 'carcass' });
  const sp = get('sidePanel');
  if (sp) sh.push({ shape: 'rect', part: 'carcass', x: sp.z, y: fy(sp.y + sp.h), w: D, h: sp.h, fill: null });

  for (const p of ps.filter((x) => x.kind === 'shelf')) {
    sh.push({ shape: 'rect', part: 'shelf', x: p.z, y: fy(p.y + p.h), w: p.d, h: p.h, fill: 'shelf' });
  }
  for (const p of ps.filter((x) => x.kind === 'drawerBox')) {
    sh.push({ shape: 'rect', part: 'drawerBox', x: p.z, y: fy(p.y + p.h), w: p.d, h: p.h, fill: 'drawerBox' });
  }
  for (const p of ps.filter((x) => x.kind === 'rail')) {
    sh.push({ shape: 'rect', part: 'rail', x: p.z, y: fy(p.y + p.h), w: p.d, h: p.h, fill: 'rail' });
  }
  for (const p of ps.filter((x) => x.kind === 'cell')) {
    sh.push({ shape: 'rect', part: 'cell', x: p.z, y: fy(p.y + p.h), w: p.d, h: p.h, fill: 'cell' });
  }

  const t = get('top');
  if (t) sh.push({ shape: 'rect', part: 'top', x: t.z, y: fy(t.y + t.h), w: t.d, h: t.h, fill: 'top' });
  const bs = get('backsplash');
  if (bs) sh.push({ shape: 'rect', part: 'backsplash', x: bs.z, y: fy(bs.y + bs.h), w: bs.d, h: bs.h, fill: 'backsplash' });

  for (const p of ps.filter((x) => x.kind === 'basin')) {
    const m = p.meta;
    const th = 18;
    const y0 = fy(p.y + p.h);
    if (m.type === 'undermount') {
      sh.push({ shape: 'path', part: 'basin', d: basinSectionPath(p, th), fill: 'basin' });
      sh.push({ shape: 'path', part: 'basinCavity', d: basinCavityPath(p, th), fill: 'basinInner' });
    } else {
      sh.push({ shape: 'path', part: 'basin', d: vesselSectionPath(p, th), fill: 'basin' });
      sh.push({ shape: 'path', part: 'basinCavity', d: vesselCavityPath(p, th), fill: 'basinInner' });
    }
    void y0;
  }

  for (const p of ps.filter((x) => x.kind === 'faucet')) {
    sh.push({ shape: 'rect', part: 'faucet', x: p.z, y: fy(p.y + p.h), w: p.d, h: p.h, fill: 'faucet' });
  }

  sh.push(...layoutKey(L, cabinet.width));
  return sh;
}

function layoutKey(L, cabW) {
  const out = [];
  const KEY_Y = -120;
  const KEY_H = 46;
  let x = 0;
  for (const c of L.cells) {
    out.push({
      shape: 'rect', part: 'layoutKey',
      x, y: KEY_Y, w: c.w, h: KEY_H,
      fill: c.kind === 'door' ? 'cell' : c.kind === 'drawer' ? 'carcass' : 'basinInner',
    });
    out.push({
      shape: 'text', part: 'layoutKeyText',
      x: x + c.w / 2, y: KEY_Y + 32, text: LAYOUT_LABEL[c.kind] ?? c.kind,
      size: 20, anchor: 'middle', fill: 'dimText',
    });
    x += c.w;
  }
  void cabW;
  return out;
}

export const LAYOUT_LABEL = {
  drawer: '抽', door: '门', open: '开放格', basin: '盆胆',
};

function basinSectionPath(p, th) {
  const { z, d, y, h } = p;
  const topY = fy(y + h);
  return `M ${z} ${fy(y)} L ${z + th * 2} ${topY} L ${z + d - th * 2} ${topY} L ${z + d} ${fy(y)} Z`;
}
function basinCavityPath(p, th) {
  const { z, d, y, h } = p;
  const topY = fy(y + h);
  return `M ${z + th * 2} ${fy(y)} L ${z + th * 2 + th} ${topY + th} L ${z + d - th * 2 - th} ${topY + th} L ${z + d - th} ${fy(y)} Z`;
}
function vesselSectionPath(p, th) {
  const { z, d, y, h } = p;
  return `M ${z + th} ${fy(y)} L ${z + th * 2} ${fy(y + h)} L ${z + d - th * 2} ${fy(y + h)} L ${z + d - th} ${fy(y)} Z`;
}
function vesselCavityPath(p, th) {
  const { z, d, y, h } = p;
  return `M ${z + th * 2} ${fy(y)} L ${z + th * 2 + th} ${fy(y + h - th)} L ${z + d - th * 2 - th} ${fy(y + h - th)} L ${z + d - th * 2} ${fy(y)} Z`;
}
```

```js
import { parts } from './parts.js';
import { solve } from './solve.js';
import { front, plan, section, bbox } from './project.js';

export const WHITEMODEL = {
  wall: '#f4f4f2',
  wallT: '#e6e6e2',
  floor: '#9a9a9a',
  stroke: '#000000',
  strokeWidth: 1,
  mirror: '#ffffff',
  mirrorInner: '#f0f0ee',
  top: '#dcdcda',
  backsplash: '#e9e9e7',
  basin: '#fbfbfa',
  basinInner: '#e6e6e4',
  carcass: '#d2d2d0',
  cell: '#f4f4f3',
  toe: '#c2c2c0',
  shelf: '#d8d8d6',
  drawerBox: '#e0e0de',
  rail: '#a9a9a7',
  faucet: '#c6c6c4',
  handle: '#c6c6c4',
  drain: 'none',
  dimText: '#333333',
};

const esc = (s) =>
  String(s).replace(/[&<>"]/g, (c) => ({ '&': '&amp;', '<': '&lt;', '>': '&gt;', '"': '&quot;' }[c]));

function num(v, label) {
  const r = Math.round(v * 1000) / 1000;
  if (!Number.isFinite(r)) throw new Error(`${label} 不是有限数：${v}`);
  return r;
}

function resolve(key) {
  if (key === null || key === undefined) return null;
  return WHITEMODEL[key] ?? key;
}

const FONT = '"Microsoft YaHei","PingFang SC","Noto Sans SC",sans-serif';

function shapeToSVG(s) {
  const strokeKey = s.stroke === undefined ? 'stroke' : s.stroke;
  const stroke = resolve(strokeKey);
  const sw = s.sw ?? (stroke ? WHITEMODEL.strokeWidth : 0);
  const dash = s.dash ? ` stroke-dasharray="${s.dash}"` : '';
  const op = s.op != null ? ` opacity="${s.op}"` : '';
  const st = stroke ? ` stroke="${stroke}" stroke-width="${num(sw, 'sw')}"` : ' stroke="none"';

  switch (s.shape) {
    case 'rect':
      return `<rect x="${num(s.x, 'x')}" y="${num(s.y, 'y')}" width="${num(s.w, 'w')}" height="${num(s.h, 'h')}"${s.rx ? ` rx="${num(s.rx, 'rx')}"` : ''} fill="${resolve(s.fill) ?? 'none'}"${st}${dash}${op}/>`;
    case 'line':
      return `<line x1="${num(s.x1, 'x1')}" y1="${num(s.y1, 'y1')}" x2="${num(s.x2, 'x2')}" y2="${num(s.y2, 'y2')}"${st}${dash}${op}/>`;
    case 'ellipse':
      return `<ellipse cx="${num(s.cx, 'cx')}" cy="${num(s.cy, 'cy')}" rx="${num(s.rx, 'rx')}" ry="${num(s.ry, 'ry')}" fill="${resolve(s.fill) ?? 'none'}"${st}${dash}${op}/>`;
    case 'path':
      return `<path d="${s.d}" fill="${resolve(s.fill) ?? 'none'}"${st}${dash}${op}/>`;
    case 'text':
      return `<text x="${num(s.x, 'x')}" y="${num(s.y, 'y')}" fill="${resolve(s.fill) ?? WHITEMODEL.dimText}" font-size="${num(s.size ?? 20, 'size')}" font-family='${FONT}' text-anchor="${s.anchor ?? 'middle'}"${op}>${esc(s.text)}</text>`;
    default:
      throw new Error(`未知图形类型：${s.shape}`);
  }
}

export function renderSVG(shapes, box) {
  const body = shapes.map(shapeToSVG).join('');
  return `<svg xmlns="http://www.w3.org/2000/svg" width="${num(box[2], 'box.w')}mm" height="${num(box[3], 'box.h')}mm" viewBox="${box.map((v) => num(v, 'box')).join(' ')}">${body}</svg>`;
}

export function drawAll(spec) {
  const L = solve(spec);
  const ps = parts(spec);
  const out = {};
  for (const [key, project] of [['front', front], ['plan', plan], ['section', section]]) {
    const shapes = project(ps, spec, L);
    const box = bbox(shapes);
    out[key] = { shapes, box, svg: renderSVG(shapes, box) };
  }
  return out;
}
```

```js
export const BASIN_LABEL = {
  vessel: '台上盆',
  undermount: '台下盆',
  integral: '一体盆',
};

export const CELL_LABEL = {
  drawer: '抽屉',
  door: '门',
  open: '开放格',
  basin: '盆胆',
};

const SHORT = { drawer: '抽', door: '门', open: '开放格', basin: '盆胆' };

function fmt(n) {
  return Number.isInteger(n) ? String(n) : String(Math.round(n * 10) / 10);
}

function bandSummary(L) {
  const parts = [];
  L.bands.forEach((bl, i) => {
    const counts = new Map();
    for (const c of bl.cells) counts.set(c.kind, (counts.get(c.kind) ?? 0) + 1);
    const desc = [...counts].map(([k, n]) => `${SHORT[k] ?? k}×${n}`).join(' ');
    const pos = i === 0 ? '下带' : i === L.bands.length - 1 ? '上带' : `中带${i}`;
    parts.push(`${pos} ${desc}`);
  });
  return parts.join('  /  ');
}

export function annotationLines(spec, L) {
  if (!spec.annotations || !spec.annotations.enabled) return [];
  const { cabinet, top, basin } = spec;
  const out = [spec.name];

  out.push(`台面：${top.material} ${fmt(top.thickness)}厚 · 挡水高 ${fmt(top.backsplash.height)}`);

  const basinSize = basin.type === 'undermount'
    ? `${fmt(basin.width)}×${fmt(basin.depth)}`
    : `${fmt(basin.width)}×${fmt(basin.depth)}×${fmt(basin.height)}`;
  out.push(`盆：  ${BASIN_LABEL[basin.type]} ${basinSize} ×${basin.count} 个`);

  const mount = cabinet.mount === 'wall'
    ? `悬空 ${fmt(cabinet.wallGap)}`
    : '落地';
  out.push(
    `主柜：${fmt(cabinet.width)}×${fmt(cabinet.height)}×${fmt(cabinet.depth)} · ${mount}` +
    ` · ${cabinet.boardMaterial} 板厚 ${fmt(cabinet.sidePanel)}`,
  );

  out.push(`分区：${bandSummary(L)}`);
  out.push(`缝宽：${fmt(cabinet.gap)}`);

  return out;
}
```

```js
function annotationBlock(spec, L, shapes) {
  const lines = annotationLines(spec, L);
  if (!lines.length) return [];
  const b = bbox(shapes, 0);
  const fs = spec.annotations.fontSize ?? 22;
  const lh = spec.annotations.lineHeight ?? 34;
  const right = spec.annotations.position === 'below';
  const x = right ? b[0] + 10 : b[0] + b[2] + 30;
  const y0 = right ? b[1] + b[3] + lh * 2 : b[1];
  return lines.map((t, i) => ({
    shape: 'text', part: 'dimText',
    x, y: y0 + i * lh, text: t,
    size: i === 0 ? fs * 1.15 : fs,
    anchor: right ? 'start' : 'start',
    fill: 'dimText',
  }));
}
```

> `"right"`（默认），标注排在图形右侧，最终 `bbox()` 已能覆盖到它，无需额外处理。

```js
  const a = document.createElement('a');

  const url = URL.createObjectURL(new Blob([svg], { type: 'image/svg+xml;charset=utf-8' }));
  img.onload = () => {
    const cv = document.createElement('canvas');

    ctx.fillRect(0, 0, cv.width, cv.height);
    ctx.drawImage(img, 0, 0, cv.width, cv.height);
    cv.toBlob((b) => download(b, `${spec.name}-${key}.png`), 'image/png');
    URL.revokeObjectURL(url);
  };
```

````markdown
# 浴室柜画图工具

用自然语言描述需求 → 立刻出正视图 / 俯视图 / 剖面图，客户确认方案用。

## 打开方式

双击 `run.bat`。会弹出一个独立窗口（用的是 Windows 自带的 Edge，不需要安装任何东西）。

## 核心概念

- **参数决定一切。** 改任何数字，三张图立刻重算。
- **没有档位、没有下限上限、没有"这个尺寸不标准"的提示。** 这是定制业务，所有尺寸都能随便填。
- **预设只是起点。** 点一下预设填一整套合理值，之后每个数字都能单独改。
- **面板缝宽**默认 2mm，来自团体标准 T/FSWA 01-2021 的位差度要求（≤2.0mm）。

## 分区怎么填

柜体被分成若干"带"，从下往上。每条带再切成 **列 × 行** 的网格，每格是一个抽屉 / 门 / 开放格 / 盆胆。

- **列宽比** `1,1` = 对半分；`3,1,3` = 两侧宽中间窄（中抽）
- **行高比** `2,1` = 下大上小；`2,1.5,1` = 三抽递减
- **格子类型** 留空 = 整条带按「类型」来；填 `door,drawer,door` = 逐格指定

可填的格子类型：`drawer` 抽屉、`door` 门、`open` 开放格、`basin` 盆胆。

## 导出

- **PNG** —— 发微信
- **SVG** —— 存档、给工厂

```
````
