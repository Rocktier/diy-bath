**Goal:** 交付一个可用的 MVP：导购员能打开 exe，转着看 3D、切回三视图、改参数实时更新、导出 PNG。

**Architecture:** `parts.js` 产出的 `Part[]` 本来就含 `x/y/z/w/h/d` 六个值，是 3D 数据源。`world.js` 负责工程坐标→Three.js 坐标的映射（纯函数，可测）。`three-view.js` 把 `Part[]` 变成可轨道旋转的场景。三视图（`project.js`）与 3D **共用同一份 `Part[]`**，几何必然一致。

**Tech Stack:** Three.js 0.180（MIT，动态 import）、Vite 6、Tauri 2、vitest 3。零构建产物一致性要求——所有 JS 走 Vite，不允许裸 `<script type="module">` 直开。

- [ ] **Step 4: 写 src/silhouette.js**

```js
/**
 * 3D 场景描述。
 *
 * 为什么要这一层：three-view.js 需要 WebGL 和 DOM，Node 里测不了。
 * 把「画哪些零件、什么颜色、多大」抽成纯数据，就能在 Node 里断言场景内容——
 * 盆在不在台面之上、面板贴不贴前沿、抽屉数对不对，这些回归肉眼盯不住。
 *
 * 输出的坐标仍是**工程坐标**，映射到 Three.js 是 three-view.js 的事。
 */

import { parts } from './parts.js';
import { colorOf, isVisible, NEEDS_EDGE } from './world.js';

/** 地面比柜体大多少倍，够放影子就行 */
const GROUND_SPREAD_X = 4;
const GROUND_SPREAD_Z = 6;

export function scenePlan(spec) {
  const list = [];

  for (const p of parts(spec)) {
    if (!isVisible(p.kind)) continue;
    list.push({
      kind: p.kind,
      x: p.x, y: p.y, z: p.z,
      w: p.w, h: p.h, d: p.d,
      color: colorOf(p.kind),
      edge: NEEDS_EDGE.has(p.kind),
    });
  }

  let minX = Infinity, minY = Infinity, minZ = Infinity;
  let maxX = -Infinity, maxY = -Infinity, maxZ = -Infinity;
  for (const p of list) {
    minX = Math.min(minX, p.x);
    minY = Math.min(minY, p.y);
    minZ = Math.min(minZ, p.z);
    maxX = Math.max(maxX, p.x + p.w);
    maxY = Math.max(maxY, p.y + p.h);
    maxZ = Math.max(maxZ, p.z + p.d);
  }
  if (!list.length) {
    minX = minY = minZ = 0;
    maxX = maxY = maxZ = 1;
  }

  const W = spec.cabinet.width;
  const D = spec.cabinet.depth;

  return {
    parts: list,
    ground: {
      y: 0,
      w: W * GROUND_SPREAD_X,
      d: D * GROUND_SPREAD_Z,
      centerX: W / 2,
      centerZ: D / 2,
    },
    target: {
      x: (minX + maxX) / 2,
      y: (minY + maxY) / 2,
      z: (minZ + maxZ) / 2,
    },
    bounds: { minX, minY, minZ, maxX, maxY, maxZ },
  };
}
```

- [ ] **Step 3: 拆出 _clearGroup**

```js
  /**
   * 清空场景。
   *
   * geometry / material 必须 dispose，否则改十几次参数显存就撑爆，
   * 得重开应用。这是从 2D 版本学来的——SVG 是字符串没有这个问题，
   * 3D 的 GPU 资源不会自动回收。
   */
  _clearGroup() {
    for (let i = this.group.children.length - 1; i >= 0; i--) {
```

### Task 5: 产物完整性检查

**Files:**
- Create: `scripts/check-bundle.mjs`
- Modify: `package.json`

**Interfaces:**
- Consumes: `dist/` 产物
- Produces: 退出码 0 = 通过，1 = 有问题

**为什么需要：** Three.js 走动态 import。如果某次改动让动态 import 变成静态，
主包会从 47KB 涨到 550KB——用户等三视图也要多等几秒，而且没有任何报错。
这个检查能在构建后立刻发现。

- [ ] **Step 1: 写 scripts/check-bundle.mjs**

```js
/**
 * 检查构建产物是否合理。
 *
 * 重点是代码分割有没有被破坏。Three.js 有 500KB，
 * 一旦被静态 import 进主包，三视图模式也要多等几秒下载，
 * 而且不会报任何错——所以必须在构建后断言。
 */
import { readdirSync, readFileSync, statSync } from 'node:fs';
import { join } from 'node:path';

const DIST = 'dist';
const ASSETS = join(DIST, 'assets');

/** 主包上限。实测拆分后是 47.8KB，留一倍余量 */
const MAIN_LIMIT_KB = 100;

let bad = 0;

const fail = (msg) => {
  console.error(`  ✗ ${msg}`);
  bad++;
};
const ok = (msg) => console.log(`  ✓ ${msg}`);

let files;
try {
  files = readdirSync(ASSETS).filter((f) => f.endsWith('.js'));
} catch {
  console.error('找不到 dist/assets，先跑 npm run build');
  process.exit(1);
}

if (!files.length) {
  console.error('dist/assets 里没有 js 文件');
  process.exit(1);
}

const sizes = files.map((f) => ({ name: f, kb: statSync(join(ASSETS, f)).size / 1024 }));
const main = sizes.find((s) => s.name.startsWith('index-'));
const three = sizes.find((s) => s.name.startsWith('three-view-'));

console.log('产物:');
for (const s of sizes) console.log(`  ${s.name.padEnd(28)} ${s.kb.toFixed(1)} KB`);

if (!main) fail('找不到主包 index-*.js');
else if (main.kb > MAIN_LIMIT_KB) {
  fail(`主包 ${main.kb.toFixed(1)}KB 超过 ${MAIN_LIMIT_KB}KB —— Three.js 可能被静态 import 了`);
} else {
  ok(`主包 ${main.kb.toFixed(1)}KB，在预算内`);
}

if (three) {
  ok(`Three.js 独立成块 ${three.kb.toFixed(1)}KB，仅在进 3D 模式时下载`);
} else {
  console.warn('  ! 没找到 three-view-*.js —— 如果这是有意的（暂不做 3D）可以忽略');
}

const html = readFileSync(join(DIST, 'index.html'), 'utf8');
if (!/<script[^>]+type="module"/.test(html)) fail('index.html 里没有 type=module 的脚本');
else ok('index.html 引用了 module 脚本');

if (/NaN|undefined/.test(html)) fail('index.html 含 NaN / undefined');
else ok('index.html 无 NaN / undefined');

console.log(bad ? `\n${bad} 处问题` : '\n产物检查通过');
process.exit(bad ? 1 : 0);
```
