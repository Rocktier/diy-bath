# VanityLab — 参数化浴室柜画图工具

轻量、国内门店用的浴室柜 3D 设计器。内部统一 mm（可切 inch），**界面全中文**（英文字库保留在代码中但不显示）。Web 先行，纯本地、零外网依赖。

## 运行

### 网页版
```bash
node _serve.js
# 打开 http://127.0.0.1:8765/index.html
```
Three.js 等依赖已本地化到 `vendor/`，离线可用。`index.html` 也可用本地服务器直接打开；部分浏览器限制 file:// 的 ES Module，推荐用上面的服务器。

### 桌面版（Electron）
```bash
npm install
npm start
# 打包：npm run build:win / build:mac / build:linux
```

### PWA
通过本地服务器访问后可"安装应用"；`sw.js` 提供离线回退，导航优先走网络以便及时看到更新。

## 功能

- **组件库（6 大分组，全部折叠收纳）**：柜体（单/双盆 600–1400、落地、窄型、铝合金、一门双抽）、门板与收纳（抽屉柜/门柜/开放格/左右侧边柜）、镜柜（等分/非等分双门、单门、三开门美妆、全开放、LED 超薄）、镜片（方/圆/椭圆/跑道/异形拱门）、灯光（无灯/顶灯条/背光/环形跑道灯/双侧灯/前发光，作用于选中镜片或镜柜）、五金（长拉手/隐形拉手/圆拉手/无拉手）。每个细项有专属 SVG 图标与简要说明。
- **风格参考库**：7 个品牌通用风格预设（整套柜 + 镜柜），品牌名仅作风格参考——见 [LEGAL.md](LEGAL.md)。
- **参数化**：宽/深/高、抽屉数、门数、**左门占比（镜柜一大一小）**、镜片形状/边框、灯光样式、拉手、盆型、挂墙/落地、安装高度。
- **3D**：旋转/缩放/平移、正/侧/顶视图、自动取景、SketchUp 式标注（箭头端点、文字贴线、白描边）。
- **交互**：拖入组件、3D 直接拖动、X/Z 数值定位、0/90/180/270 旋转、贴墙约束（不穿墙）、居中对齐吸附（虚线参考）、同类型组件替换。
- **造型工艺**：抽屉拉出 / 柜门开合动画（按钮或双击组件）、程序化 PBR 纹理 + 52 张 512px 贴图、LED 真实光影（点光源 + 光晕）。
- **开孔**：台面按盆位/龙头孔真实切割（Shape + holes 挤出），单盆/双盆。
- **校验**：三轴重叠碰撞检测、约束求解与一键自动修复。
- **方案**：多方案管理（新建/另存/重命名/删除/切换）、JSON 导入导出、localStorage 自动保存、撤销重做。
- **导出**：PNG 截图、BOM 物料清单 CSV、GLB 模型。

## 文件
| 文件 | 作用 |
|------|------|
| `index.html` | 应用主体（单文件） |
| `_serve.js` | 零依赖本地静态服务器 |
| `vendor/` | 本地化的 Three.js 及 addons（零外网） |
| `manifest.webmanifest`, `sw.js`, `icon.svg` | PWA |
| `main.js`, `package.json` | Electron 桌面打包 |
| `tools/gen-textures.js`, `assets/textures/` | PBR 贴图生成脚本与资产 |
| `LEGAL.md` | 品牌/法律风险说明与发布前 checklist |
| `../task_plan.md`, `../findings.md`, `../progress.md` | 规划台账 |

## 已知边界
- A 阶段：无后端/云，方案只在 localStorage + JSON 文件互传；B 阶段（经销商 SaaS）尚未启动。
- 定位：纯出图应用（3D 图 + 标注 + BOM/PNG/GLB 导出），不做报价/计价。
- 门抽形态：已支持子母抽（不等高双抽）、左右单开门、一门双抽左右分区。
- I18N.en 语库保留在代码中但界面强制中文；LEGAL.md 为中英法律文档。
- 移动端为响应式适配，尚未真机逐机型验证。
